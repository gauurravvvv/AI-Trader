Multi-agent research platform · planning complete

Aegis Trading Desk A team of Claude agents researches US equities, Indian equities and crypto around the clock, argues each idea from both sides, audits its own reasoning, and places the result against paper accounts — logging every step so the whole thing can be scored.

Paper money only
The organising idea

Intelligence goes down as you approach the money

Every tier in this system is less clever and more deterministic than the one before it. That gradient is deliberate. An agent that invents a support level costs you a mediocre entry. An agent that invents a position limit costs you the account — so position limits are ordinary code with ordinary tests, and no language model is anywhere near them.

Two components can stop a trade outright. The Auditor scores the reasoning itself, not the stock, and refuses to pass anything below its confidence floor. The Risk Officer checks the hard caps and is the only component in the system that can say no and mean it.

Three markets, one interface

Where the orders go

All three implement the same adapter and pass the same conformance suite, so agent code never knows which venue it is talking to. Adding a fourth is one file and a green test run.

MarketVenueShipsWhy this one
CryptoBinance Spot Testnet1stOpen 24/7, so the real-time loop can be debugged at 11pm on a Sunday instead of waiting for Monday's open.
US equitiesAlpaca Paper2ndFree, real-time, and open to anyone with an email. The free tier serves IEX rather than consolidated prices, so US fills carry an extra slippage penalty.
IndiaIn-house simulator3rdNo Indian broker offers a real paper sandbox, and SEBI's algo framework has required static-IP whitelisting, a registered strategy ID and exchange empanelment since April. Simulating keeps the regulatory surface at zero.
On the simulator

A fill model that flatters you is not a simulator, it is a lie generator. Every simulated fill pays half the spread, slippage that scales superlinearly with participation rate, at least 300 ms of latency, and the full Indian cost stack — brokerage, STT, exchange charges, GST, stamp duty. The acceptance test is that replaying a historical week produces worse results than naive close-price fills.

Delivery — each phase ends at a gate

Order of work

Everything that moves money is proven before anything that thinks about it is written. The measuring instrument ships early too — a pipeline that has run for two months with no way to score it has produced nothing.

00

Foundation

gate  The paper-only invariant is enforced by a frozen endpoint allowlist and a test that fails the build if a live broker hostname appears anywhere in source.

01

Broker spine

gate  A hand-placed order round-trips: fill arrives over WebSocket, ledger updates, reconciliation agrees with the venue. No agents yet.

Risk, router, email

gate  A kill-switch drill cancels everything within one tick, and a deliberate cap breach is rejected, logged and emailed.

04

gate  Read ten shadow decisions by hand. If the reasoning is not something you would act on, the prompts are wrong and no downstream engineering fixes that.

What this can and cannot promise

The output is a verdict, not a bankroll

No design guarantees profit, and one that assumes it is the design that loses money. Three things stay true and are built into the requirements rather than bolted on as disclaimers.

There is no published evidence that LLM agents have an edge in liquid markets. Every framework this project draws from — including the two most-starred ones on GitHub — ships with a research-only disclaimer and no audited track record.

Paper trading flatters you. No queue position, no market impact, and on the free US tier, single-exchange prices. Slippage and costs are modelled explicitly on all three venues so the gap stays visible.

The measurable question is the deliverable. Does the pipeline beat buy-and-hold after costs, and is the sample large enough to believe? If the honest answer is no, that is a successful experiment run in paper money — and it is worth considerably more than a confident system with no way to check itself.
